# Чек-лист доказательств ПЗ-3

Перед сдачей каждый студент проверяет, что для его личной части доступны:

- [ ] ссылка на собственную задачу, ветку и Pull Request;
- [ ] независимый review от второго участника;
- [ ] ссылка на merge в `main`;
- [ ] тег `0104-pz01-<код>-v1` и полный SHA;
- [ ] скриншот личного фрагмента каркаса;
- [ ] скриншоты сборок Debug и Release;
- [ ] скриншот запуска опубликованного Release вне исходников;
- [ ] скриншоты штатного и ошибочного запусков конфигурации;
- [ ] протокол независимого воспроизведения;
- [ ] ссылка и скриншот GitHub Actions для сдаваемого commit;
- [ ] скриншот неуспешной автоматической проверки при намеренно нарушенном условии;
- [ ] корректный код после эксперимента восстановлен.
