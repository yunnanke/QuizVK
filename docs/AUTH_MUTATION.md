# Мутационная проверка входа по паролю

Интеграционные тесты в `tests/QuizMvp.Tests/AuthControllerTests.cs` содержат
сценарии входа с неверным паролем. Они должны обнаруживать изменение, которое
обходит сравнение введённого пароля с сохранённым хешем.

Чтобы повторить эксперимент, временно замените вызов
`VerifyPassword(password, user.PasswordHash)` в условии успешного входа в
`QuizMvp/Controllers/AccountController.cs` на `true`. Сохраните проверку на
пустой пароль. Затем выполните команду:

```powershell
dotnet test tests/QuizMvp.Tests/QuizMvp.Tests.csproj --filter "FullyQualifiedName~Login_WrongPassword"
```

Ожидаемый результат: три сценария с неверным непустым паролем завершаются
ошибкой теста, потому что вход ошибочно перенаправляет пользователя на главную
страницу. Сценарий с пустым паролем по-прежнему отклоняется отдельной проверкой.
После эксперимента сразу восстановите исходное условие и проверьте весь набор:

```powershell
dotnet test tests/QuizMvp.Tests/QuizMvp.Tests.csproj
```

Не сохраняйте и не отправляйте изменённую реализацию контроллера. Приложение
хранит хеши паролей в формате SHA-256/Base64 и использует MVC-сессии. JWT,
BCrypt и API-контракты статусов, упомянутые в старых материалах отчёта, в этом
проекте не реализованы.
