# Definition of Done — Quizzy

Изменение считается завершённым, если выполнены все пункты ниже.

## 1. Общие критерии
- Есть задача с целью, затрагиваемыми требованиями и рисками.
- Результат проверяем: тесты, воспроизводимый сценарий или наблюдаемый контракт API.
- Код, тесты и документация изменены согласованно.
- Применимые проверки пройдены и видимы.

## 2. Технические критерии
- `dotnet build QuizMvp.sln` — 0 ошибок.
- Новые nullable-предупреждения не добавляются; существующие учитываются в плане.
- Изменение не нарушает NFR-01…NFR-05.
- В baseline не добавлены PostgreSQL, отдельный WebSocket или иной крупный ресурс без отдельного решения команды.

## 3. Процессные критерии
- Изменение выполнено в отдельной ветке.
- Задача связана с требованием (FR/NFR) и рисками.
- До слияния выполнены сборка и применимые проверки.
- Для существенных изменений получен review.
- Результат и известные риски зафиксированы в PR/MR.

## 4. Существенные изменения
Существенными считаются изменения требований, модели данных, алгоритма начисления
баллов, авторизации, внешнего ресурса или публичного контракта API. Для них review
обязателен.

## 5. Таблица подтверждений (заполняется по факту)

| Элемент DoD | Фактическое подтверждение |
|-------------|---------------------------|
| Постановка задачи | Issue №__ |
| Изменение в отдельной ветке | PR №__, ветка `feature/__` |
| Сборка | `dotnet build QuizMvp.sln` — 0 ошибок |
| Автоматические проверки | CI run __: job verify — success |
| Независимая проверка | Review в PR №__, замечания учтены |
| Объединение | PR №__ — merged DD.MM.YYYY |
