# Quality Gate v0 — Quizzy

Quality Gate — обязательный набор проверок, которые должны пройти изменения
перед слиянием. Если хотя бы одна проверка не пройдена — слияние блокируется.

## 1. Состав Quality Gate v0

| Проверка | Условие прохождения |
|----------|---------------------|
| Сборка | `dotnet build QuizMvp.sln` — 0 ошибок |
| Связь с задачей | изменение связано с задачей и требованиями (FR/NFR) |
| Видимость результата | результат проверки виден в PR/MR и карточке доказательств |
| Review | для существенных изменений — пройден |
| Воспроизводимость | коммит позволяет повторить проверку |
| Ограничения baseline | PostgreSQL, отдельный WebSocket и крупные ресурсы не добавлены молча |

## 2. Автоматическая часть
На текущей контрольной точке автоматизирована сборка. На дату подготовки первого
комплекта сборка успешна: 0 ошибок, 34 nullable-предупреждения, которые необходимо
планово устранять.

## 3. Ручная часть
- Связь изменения с задачей и требованиями проверяется в PR/MR.
- Существенные изменения проходят review.
- Результат и риски фиксируются в PR/MR.

## 4. Связь с DoD
Quality Gate v0 покрывает техническую и процессную часть DoD:
- «применимые проверки» → сборка и проверки в PR/MR;
- «результат видим» → карточка доказательств;
- «код, тесты и документация согласованы» → проверяется на review;
- «baseline не расширяется молча» → отдельное правило Quality Gate.
