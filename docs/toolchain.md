# Инструментальный контур QuizVK

- Проект: QuizVK (MVP Quizzy)
- Авторы: Матвеева Ю. П., Голубев Е. Е.
- Версия документа: 1.0
- Дата: 17.10.2026

## Назначение

Документ описывает средства, необходимые для получения запускаемого компонента QuizVK из чистого клона репозитория, проверки его основной логики и автоматического контроля изменений.

Основной проверяемый модуль: `QuizMvp/Services/AnswerScoringService.cs`.

## Позиции инструментального контура

| Позиция | Средство | Назначение | Подключение | Статус |
|---|---|---|---|---|
| Сборка | .NET SDK 8, MSBuild | Восстановление, компиляция и подготовка приложения | `dotnet restore QuizMvp.sln`, `dotnet build QuizMvp.sln -c Release` | Работает локально |
| Управление зависимостями | NuGet, `PackageReference` | Получение библиотек и фиксация их версий | `QuizMvp/QuizMvp.csproj` | Работает |
| Хранение данных | SQLite, EF Core | Локальное хранение квизов, сессий и ответов | строка `DefaultConnection` в `QuizMvp/appsettings.json` | Работает для MVP |
| Веб-сервер | ASP.NET Core MVC | Обработка HTTP-запросов, маршрутов, сессий и представлений | `QuizMvp/Program.cs` | Работает |
| Событийное взаимодействие | SignalR | Обновление событий квиза и сессии | `QuizHub` по маршруту `/quizHub` | Подключено |
| Тестирование | `QuizMvp.LogicTests` | Проверка правила начисления баллов | `QuizMvp.LogicTests/Program.cs` | Работает локально |
| Статический анализ | Nullable-аннотации и предупреждения компилятора | Поиск части ошибок до запуска программы | `<Nullable>enable</Nullable>` и `dotnet build` | Используется частично |
| Динамическая диагностика | Логирование ASP.NET Core, Visual Studio / .NET debugger | Диагностика запуска и ошибок времени выполнения | `appsettings.json`, запуск в Debug | Подключено частично |
| Профилирование | `dotnet-counters`, `dotnet-trace` | Наблюдение за нагрузкой, памятью и процессом .NET | Устанавливается и запускается при исследовании производительности | Запланировано |
| Автоматические проверки | GitHub Actions | Сборка и запуск LogicTests при изменениях | `.github/workflows/quality-gate.yml` | Workflow настроен |
| Контроль версий | Git и GitHub | Ветки, Pull Request, review, теги сдачи | Репозиторий `github.com/yunnanke/QuizVK` | Используется |
